# Companion and Recovery Field production audit

**Audit date:** 2026-08-08

## Low-capacity path

The shortest path is Now → Notice a change → one of four large choices. The first useful state is saved after one tap and the user is explicitly allowed to stop. No login, explanation, score, streak, forced detail or network is required. The next optional path is visually secondary.

The full check-in can switch to quiet capacity. It then shows three dimensions rather than six, uses one step per route, reduces motion through the existing quiet/reduced-motion system and leaves a clear close/back route. On-device use remains available offline.

Static interaction inspection finds the intended useful path within two decisions, consistent with the 10–30 second design target. Actual timing with tired/high-craving participants remains a beta acceptance test rather than a claimed laboratory result.

## Personalization correction and evidence

The audit found and fixed a serious subtle defect: in a quiet check-in, hidden dimensions previously retained old values and could appear as if they had just been observed. Each check-in now records `observedDimensions`; unobserved dimensions are neutral/uncertain, cannot become bottlenecks and cannot receive a false trajectory claim.

Route selection uses the current observed geometry and explicit pressures:

- changed sleep alters the body-route rationale and goal;
- nearby craving alters internal-load rationale, priority and intervention domains;
- isolation/conflict/low connection alters the reconnection rationale and priority;
- low capacity limits each route to one lower-cost action;
- a used-intervention set keeps all three route steps distinct in a single recommendation result;
- exactly one route is marked as the accessible starting place while two alternatives preserve agency.

Automated tests verify three distinct routes, one best next step, low-capacity simplification, no false hidden-dimension claims, different sleep/craving/isolation rationales, non-duplicated interventions, ≥40 bilingual interventions across ≥15 families, and weekly non-causality language.

## Product-language boundaries

The interface calls the result a changing field, not a diagnosis, grade or percentage. Rationale uses “may,” “appears,” and “a useful place to start.” Weekly output distinguishes observations and associations from cause. Failure/offline states do not remove the locally available Companion and Field.

## Remaining signed-device tests

- measure one-handed completion on 320–360 dp devices with TalkBack off/on;
- verify slider/choice focus order at 160% and 200% font scaling;
- time the one-tap and quiet-check-in paths with representative users;
- verify process kill immediately after persistence and after cryptographic deletion;
- assess whether route rationales feel personal in the closed beta (H3), not merely different in code.
