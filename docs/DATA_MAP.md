# Flow Hijacked Android v1.0 ground-truth data map

**Code/backend audit:** 2026-08-08  
**Applies to:** Android package `com.flowhijacked.app`, version `1.0.0`

Google defines collection as transmission off the device, including ephemeral processing and data submitted through a developer-controlled WebView. Purely on-device processing is outside the Data Safety collection declaration. This map follows that distinction.

## Storage/security facts verified in code

- Recovery, Knowledge, and Continuity use separate SQLCipher database files and separate random 256-bit keys.
- keys use SecureStore with `WHEN_UNLOCKED_THIS_DEVICE_ONLY`.
- database opening fails closed if `PRAGMA cipher_version` is unavailable.
- privacy deletion closes and deletes the database file and deletes its key, rather than merely hiding rows.
- Android backup and SecureStore backup are disabled.
- production cleartext traffic is disabled.
- WebView navigation is first-party HTTPS only; third-party cookies, mixed content, multiple windows, and automatic JavaScript windows are disabled.
- external citations must be HTTPS or a validated canonical internal path.
- focused Ask, Recovery, saved-answer/continuity, urgent-support and privacy screens are blocked from screenshots, screen recording and Android recent-app previews; editorial Explore/reading remains shareable.

## Operator facts still required before a final legal declaration

These cannot be truthfully inferred from the mobile repository:

1. Cloudflare/hosting access-log and bot-cookie retention, whether IP-derived location is retained, and subprocessors.
2. exact Ask model-provider entity, service-provider/DPA classification, regions, abuse-log settings, and retention evidence for “response storage disabled.”
3. retention of aggregate Ask feedback and canonical page measurement.
4. monitored privacy contact address and applicable controller/legal entity/address.
5. whether Android v1 will remain account-free for launch. Adding any sign-in/account creation changes this map and triggers account-deletion requirements.

The Play form must stay in draft until those five operator facts are confirmed.
